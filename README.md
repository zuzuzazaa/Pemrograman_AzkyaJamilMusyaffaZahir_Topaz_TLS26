**# Pemrograman_AzkyaJamilMusyaffaZahir_Topaz_TLS26**

Nama : Azkya Jamil Musyaffa Zahir
Kelompok : Topaz

**# Deskripsi**

**Program 1** menggunakan konsep eliminasi berulang. Program menerima nilai N sebagai jumlah astronot dan K sebagai interval eliminasi. Setiap astronot diberi status hidup, kemudian program menghitung astronot yang masih hidup hingga mencapai hitungan K untuk dieliminasi. Setelah eliminasi, nilai K diubah: jika nomor astronot yang dieliminasi genap, K bertambah 2, sedangkan jika ganjil, K berkurang 1 dengan batas minimum 2. Proses terus dilakukan sampai hanya tersisa satu astronot, yang kemudian ditampilkan sebagai astronot terakhir.

 ** Program 2** merupakan program penyandian pesan menggunakan huruf kapital A–Z. Program membaca pesan, kemudian untuk setiap karakter setelah karakter pertama, nilai huruf tersebut dijumlahkan dengan nilai huruf sebelumnya. Jika hasil penjumlahan lebih dari 26, nilainya dikurangi 26 agar tetap berada dalam rentang A–Z. Hasil perhitungan kemudian dikonversikan kembali menjadi karakter dan disimpan sebagai pesan tersandi.
